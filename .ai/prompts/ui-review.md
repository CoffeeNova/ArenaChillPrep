# UI review request

Use this template when reviewing or iterating on the addon's settings panel (or any UI). It structures the user's feedback so you can act on it without guessing. Paste it as your message (self-contained).

---

Review the settings panel (`/acp` → ArenaChillPrep → Autotrade) and describe what you see, section by section. This lets me fix layout precisely instead of guessing.

Please answer in this format:

1. **Sections** — for each box (General, Arena brackets, Ranks to pass, Timing): is the title aligned with the other titles? Does the content touch the frame edges?
2. **Overlaps / clipping** — any text or control that overlaps another, or is cut off at a frame border?
3. **Spacing** — any section where items feel too cramped, or too much empty space inside/around a box?
4. **Column balance** — do the left column (General + Brackets) and right column (Ranks + Timing) feel visually balanced? Which column looks denser/looser?
5. **Bottom of the window** — is there a large empty area, or does content fill it?
6. **Anything else** that looks off (alignment, font, disabled states).

If possible, describe positions relative to the frame ("5v5 is touching the bottom border", "Timing title is 2px lower than Ranks title") rather than "looks wrong". Screenshot descriptions are fine too.
